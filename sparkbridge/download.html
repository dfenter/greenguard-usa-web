Every product, signed, for both Ignition lines

Pick the bundle for your gateway line. Each bundle carries the module, its checksums, the signing certificate and the license. Every paid module runs on Ignition's two-hour module trial until a key file names it; Reset Trial restarts the clock. A key lifts the pause within thirty seconds with no restart. SparkLink, SparkCalc and SparkID never pause. Installation and configuration steps for every product are on the docs page.

before you install

Verify, Then Accept the Certificate

Every module is signed with the SparkBridge certificate, not an Inductive Automation one, so the gateway shows a certificate acceptance page on the first module you install. The gateway checks each module's signature against that certificate automatically on upload, so a tampered or mismatched file is rejected before it installs. Accepting the certificate once covers every module signed with it.

The checksums below are published for anyone who wants to verify a file by hand.
