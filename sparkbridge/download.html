Every product, signed, for both Ignition lines

Pick the bundle for your gateway line. Each bundle carries the module, its checksums, the signing certificate and the license. Development use is free with no time limit. When a gateway goes live, one key file licenses it with no restart. Installation and configuration steps for every product are on the docs page.

before you install

Verify, Then Accept the Certificate

Every module is signed with the SparkBridge certificate, not an Inductive Automation one, so the gateway shows a certificate acceptance page on the first module you install. Print the fingerprint from the bundled certificate and compare it against that page before accepting. Accepting once covers every module signed with it.

Check what you received against the checksums published at the bottom of this page, not against the file that traveled with it. Bundles for 8.1 and 8.3 are not interchangeable.

Two commands 
shasum -a 256 -c SHA256SUMS.txt
keytool -printcert -file sparkbridge-signing-cert.pem
