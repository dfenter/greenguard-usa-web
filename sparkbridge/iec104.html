What it does

The whole session, not just the reads

IEC 104 is a stateful protocol. Most of the work is in the parts that are not data transfer.

Session

STARTDT, TESTFR, STOPDT, and the counters

The driver runs the full APCI lifecycle with the k and w windows and the t1, t2 and t3 timers. Across a 70-second capture it exchanged 162 APDUs with zero sequence faults and answered 43 TESTFR keepalives, then shut the session down cleanly.

Data

Interrogation and spontaneous, both

General interrogation walks the outstation on connect, including the compressed SQ=1 form where one address expands into a run of information objects. After that, spontaneous reports arrive as the RTU sends them. Clock synchronisation is supported.

Structure

A protocol core with no Ignition in it

The APCI framing, ASDU codec and client state machine are plain Java with zero gateway dependencies. That is what makes the driver testable against a simulator on a laptop, and it is why 99 of its 120 tests run without a gateway at all.

Why it is on the bench

It has met a reference server, not an RTU

The distinction matters, and stating it plainly is cheaper than discovering it at a customer site.

What the capture proves

  • The framing, sequencing and session lifecycle are correct against the most widely used open reference implementation.
  • Real quirks were found and handled: the reference server withholds its STOPDT confirmation while it still holds unacknowledged I-frames, so pending acknowledgements are flushed first.
  • The module loads on a live 8.1.54 gateway with no faults and registers its device settings.

What it does not prove

  • No real outstation has been driven from a configured device yet. Acceptance requires one.
  • Time-tagged, counter and double-point types have unit tests only, because the reference server never sends them.
  • Redundancy is ordered-endpoint failover. True multi-connection redundancy groups come later; the configuration shape already allows for them.
Where it stands

Waiting on hardware

If you have an IEC 104 outstation and an hour, you are the acceptance case, and an early site shapes what ships.

Done and measured

  • 120 tests green, including 21 loopback-socket client tests against a fake server.
  • 70-second live session against lib60870: 162 APDUs, 0 sequence faults, clean shutdown.
  • Interrogation, spontaneous reporting, clock sync and TESTFR all exercised.
  • Loads and registers on a live 8.1.54 gateway.

Owed before release

  • A configured device driven against a live outstation.
  • Coverage for time-tagged, counter and double-point types against real hardware.
  • Diagnostics parity with the rest of the driver line.
  • Configuration generation, a quickstart, and a signed release.
