SparkS7

SparkS7 is a Siemens S7-1200/1500 symbolic driver that browses PLC symbols by name, including optimized (non-absolute) blocks, without a TIA export.

Version 2.7.0Ignition 8.1 and 8.3Runs on: any gateway that reaches the PLC network

1. Overview

SparkS7 is a standalone device driver, licensed and running independently of any other SparkBridge module. Module id com.sparkbridge.sparks7.

2. What You Need

  • Ignition 8.1 and 8.3.
  • An S7-1200/1500 PLC reachable over classic S7comm (ISO-on-TCP, TCP port 102).

3. Install

Install the signed module through Config > Modules > Install or Upgrade a Module; no build step is required. Module id com.sparkbridge.sparks7.

4. License

Licensed per gateway, bought once and kept, soft-licensed (io.sparkbridge.license, entitlement com.sparkbridge.sparks7). Without a verified key it runs on Ignition's two-hour module trial; a present but invalid key fails closed and blocks the device until fixed or removed.

From release 2.7.0, every SparkBridge module runs on Ignition's standard two-hour module trial (the gateway's Reset Trial button restarts the clock). A verified key overrides the trial entirely and the trial clock is then ignored. Drop the key at <data>/sparkbridge-license.key; each module re-checks the file every 30 seconds, so installing, replacing, or removing a key takes effect with no restart.

5. Configure

Config > OPC UA > Device Connections > Create new Device > the S7 device type.

SettingMeaning, default
Host, PortPLC address; ISO-on-TCP default port 102.
Rack, SlotCPU endpoint selection; this is protocol routing, not authentication.

Security notes. Classic S7comm is plaintext with no credentials, encryption, or replay protection; this is a limitation of the Siemens protocol, not an omitted driver option. Isolate TCP 102 on a dedicated VLAN or VPN and firewall it so only the Ignition gateway can reach the PLC. Do not expose the PLC on an untrusted or internet-routable network.

S7comm+ transport is disabled by default because it fails against tested real hardware. It can only be enabled with the system property sparks7.allowPlus=true (or environment variable SPARKS7_ALLOW_PLUS=true), and only on a trusted test network.

6. Operate

Keep sparks7.allowPlus off in production; it exists only for testing on a trusted network. A present but invalid license key fails the device closed rather than falling back to trial behavior, so remove or fix a bad key rather than leaving it in place.

7. Verify

See the README in the bundle for the verification procedure.

8. Troubleshoot

SymptomCause / fix
Device blocked with a valid-looking key presentAn invalid key fails closed by design; remove or replace the key file rather than expecting trial fallback.
Connection fails against real hardware with S7comm+ enabledKnown limitation; S7comm+ is off by default for this reason. Use classic S7comm.
Cannot reach the PLC from another VLANExpected if TCP 102 is isolated per the security notes; add an explicit, narrow firewall rule for the Ignition gateway only.
