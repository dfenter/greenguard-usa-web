1. Overview

SparkGantt is a Perspective component that renders a Gantt/schedule chart bound to tasks, groups, and dependency data from a dataset or from bindings. It virtualizes rows, labels, and dependency-arrow rendering once a view crosses 200 tasks, so scrolling and zooming stay responsive on large schedules. One source tree builds separate lines for Ignition 8.1 and 8.3.

SparkGantt is a display and interaction component, not a scheduling engine: it does not compute critical path, resource leveling, or auto-scheduling. It renders the tasks, groups, and dependencies you bind to it and reports drag/resize interactions back through its properties.

2. What You Need

  • Ignition 8.1 or 8.3, with the Perspective module enabled (separate build lines from one source tree).
  • No other SparkBridge module is required. SparkGantt is a standalone product with its own license.

3. Install

  1. Download the signed SparkGantt .modl matching your Ignition line (8.1 or 8.3).
  2. Gateway web UI > Config > Modules > Install or Upgrade a Module, upload the file, accept the EULA (see license.html at the repository root). Module id com.sparkbridge.sparkgantt.
  3. If self-signed, accept the untrusted-certificate warning to complete install.
  4. The component appears in the Designer Perspective palette after install; no build step or restart beyond the module install itself is required.

4. License

Soft-licensed the same way as other SparkBridge-suite modules, keyed to entitlement com.sparkbridge.sparkgantt. Drop sparkbridge-license.key in the gateway's data directory; the module re-reads it within 30 seconds. A missing license key only labels status surfaces and does not gate use. A present-but-invalid or tampered key fails startup closed and the component is not registered. Standalone paid product, sold and licensed on its own, never bundled into SparkBridge itself.

5. Configure

SparkGantt is configured entirely in the Ignition Designer property panel; there is no gateway config page.

PropertyMeaning
tasksBound task list or dataset. Schema per task: id, label, start, end, progress (0-1), group, color, dependencies, milestone, tooltip.
groupsBound group list; each group needs id and label.
datasetMappingMaps dataset columns to the task schema fields when binding a raw dataset instead of an object array.
rangeVisible time range: start, end, auto.
scaleTime-axis scale: auto, hour, day, week, month.
rowHeightPixel row height; clamped at runtime to a bounded min/max regardless of what a binding supplies.
showTodayShows today's date marker.
nowLineShows a live now-line. Not independently controllable from showToday in the current release.
readOnlyDisables drag/resize interaction when true.
selectionBound selected task id.
styleStyle tokens; dark-theme aware.

A malformed row (missing mapping column, invalid id, non-finite date, duplicate id) is not silently dropped: it is excluded from the chart and reported in a data-quality banner (.sparkgantt-data-quality-banner) showing a count with the first 20 reasons in a tooltip. An interval with end before start is rejected outright rather than clamped to zero duration.

6. Operate

Day to day, watch the data-quality banner on any view whose task binding comes from a live dataset; a nonzero issue count means some rows are not rendering. Virtualization engages automatically above 200 tasks; below that threshold every row, label, and dependency arrow renders in full. Drag and resize interactions write back through the bound task properties when readOnly is false.

7. Verify

  • Place the component in a Perspective view, bind tasks and groups, and confirm the chart renders with no data-quality banner.
  • Load a 200+ task dataset and confirm scrolling stays smooth; this is the point virtualization engages.
  • Drag a task bar (with readOnly false) and confirm the bound start/end update.

An optional status route exists for licensing telemetry; it is soft and never gates chart functionality.
