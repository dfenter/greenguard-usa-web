1. Overview

What Passage does

Passage republishes the Sparkplug namespace that SparkBridge Host holds as a live OPC-UA server address space. A non-Sparkplug client (a historian, a SCADA package, an MES, an analytics tool, a test rig) connects to Passage as an ordinary OPC-UA server and browses the same tag tree Host already built, without polling the plant. Passage is not a device driver and it does not write to the field; it exposes what Host already holds.

Passage ships as a free module included with any SparkBridge Edge or Host license.

2. What You Need

  • A SparkBridge Host gateway (Passage reads Host's tag tree).
  • Ignition 8.1.19 or newer, or Ignition 8.3.
  • A free TCP port for the OPC-UA endpoint (default 62544).
  • An OPC-UA client to consume it: a historian, SCADA package, MES, analytics tool or test rig.

3. Install

  1. Download the SparkBridge release bundle for your Ignition line from the download page.
  2. In the gateway, go to Config > Modules > Install or Upgrade a Module, and upload Provider, then Host, then Edge, in that order.
  3. Accept the certificate and license once; confirm all modules show Running. Passage is included, not a separate module upload.
  4. Upgrade every installed module together, from the same release bundle, in the same maintenance window.

4. License

Passage is free. It is included with any SparkBridge Edge or Host license and ships with no license tag required of its own.

The suite key file, when present, lives at <data>/sparkbridge-license.key and is re-checked every 30 seconds, so installing or replacing it takes effect with no restart. From release 2.7.0, SparkBridge modules run on Ignition's two-hour module trial until a verified key names the product; Passage's own license state is not gated the same way since it carries no separate license tag.

5. Configure

Current Passage configuration is file/property-based. Set these as JVM system properties in the gateway startup configuration, then restart the gateway.

unsbridge.server.enabledEnable the OPC-UA server. Default true.
unsbridge.server.portOPC-UA bind port. Default 62544.
unsbridge.server.bindAddressOPC-UA bind address. Default 127.0.0.1.
unsbridge.server.hostnameHostname advertised in OPC-UA endpoints. Default localhost.
unsbridge.server.pathOPC-UA endpoint path. Default /unsbridge.
unsbridge.server.securityDirOPC-UA security directory. Default data/unsbridge/security.
unsbridge.spike.enabledEnable the synthetic proof node. Default false.
unsbridge.server.allowAnonymousUnencryptedRemoteExplicit acknowledgement for remote anonymous unencrypted access. Default false.
unsbridge.birthcache.enabledPersist and replay the last known BIRTH set. Default true.
unsbridge.birthcache.fileBirth cache path. Default data/unsbridge-birthcache.txt.
unsbridge.birthcache.maxAgeHoursMaximum accepted cache age in hours. Default 168; 0 disables the age check.
unsbridge.birthcache.saveSecondsCache save interval in seconds. Default 60; minimum 5.
unsbridge.birthcache.deviceGraceSecondsDevice grace period after an edge NBIRTH. Default 60; minimum 1.
unsbridge.ingest.enabledEnable Sparkplug MQTT ingest. Default false.
unsbridge.broker.uriMQTT broker URI. Default tcp://127.0.0.1:1883.
unsbridge.broker.usernameMQTT broker username. Default is empty.
unsbridge.broker.clientidMQTT client id. Default sparkbridge-unsbridge; use a value beginning with sparkbridge-.

Store unsbridge.status.token and unsbridge.broker.password in the file named by unsbridge.secrets.file, default data/unsbridge-secrets.properties. Passage also supports the shared sparkbridge.broker.password fallback for broker access.

6. Operate

Passage runs passively: it serves subscriptions and browse requests against Host's live tag tree. It polls nothing in the plant. On an edge NDEATH or DDEATH, the corresponding OPC-UA nodes go to bad quality within the configured device grace period. On gateway restart, the birth cache (when enabled) replays the last known BIRTH set so clients see a populated address space immediately rather than an empty tree while Host re-establishes its own sessions.

7. Verify

Connect a third-party OPC-UA client (for example UaExpert) to the configured endpoint, browse the address space, and subscribe to a value. Confirm the value matches the Sparkplug wire within one update, with the source timestamp preserved. Confirm a node goes to bad quality within the death window after an NDEATH/DDEATH.

8. Troubleshoot

SymptomCauseFix
Client cannot connectunsbridge.server.enabled is false, or the port is blockedConfirm the property is true and the configured port is reachable from the client
Remote client refused with an anonymous/unencrypted errorunsbridge.server.allowAnonymousUnencryptedRemote is false (default)Set it to true only after accepting the security tradeoff, or configure a secured endpoint
Address space empty after restartBirth cache disabled or stale beyond unsbridge.birthcache.maxAgeHoursEnable the birth cache, or wait for Host to re-establish live BIRTH data
Broker-backed ingest not updatingunsbridge.ingest.enabled is false (default)Set it to true and confirm unsbridge.broker.uri and credentials

9. Reference

  • Default OPC-UA port: 62544.
  • Default endpoint path: /unsbridge.
  • Secrets file default: data/unsbridge-secrets.properties.
  • Birth cache file default: data/unsbridge-birthcache.txt.
