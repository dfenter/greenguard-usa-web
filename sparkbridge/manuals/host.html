Overview

1. Overview

Host subscribes to the SparkBridge broker as the Sparkplug host application, decodes every site's Edge traffic, and exposes it as a managed Ignition tag provider that behaves like any other tag source in the Designer. It publishes the Sparkplug STATE topic for its host id and can write back to the field through NCMD/DCMD. Host is bundled with SparkCalc and SparkID; other Host modules (Passage, Sentinel, FleetOps, SparkVault, SparkInject) are optional add-ons on top of it.

Host is not a broker: it needs a running Provider to subscribe to before any Edge publishes.

Install

3. Install

  1. Download the release bundle for your Ignition line from the download page: SparkBridge-Provider.modl, SparkBridge-Host.modl, SparkBridge-Edge.modl, plus SHA256SUMS.txt and sparkbridge-signing-cert.pem.
  2. Install order matters: Provider first, then Host, then Edge (and Flow, if bought). In the gateway, go to Config > Modules > Install or Upgrade a Module and upload SparkBridge-Host.modl after Provider.
  3. Accept the certificate and license once; confirm Config > Modules shows SparkBridge Host state = Running.

Upgrade every installed SparkBridge module together, from the same release bundle, in the same maintenance window. A gateway running mixed old and new module versions can disagree on which module owns a shared setting, such as hostId or foldtarget, and silently misbehave.

License

4. License

FilePer-gateway license key at <data>/sparkbridge-license.key.
Re-check intervalHost re-checks the key file every 30 seconds. Installing, replacing or removing a key takes effect with no restart.

From release 2.7.0, Host runs on Ignition's standard two-hour module trial (the gateway's Reset Trial button restarts the clock). When the trial expires with no verified key naming the product, Host publishes a retained OFFLINE STATE and closes its sessions. A key dropped in after expiry lifts the pause on its own within the 30-second re-check, no button press and no restart. A verified key overrides the trial entirely.

Configure

5. Configure

Open Config > SparkBridge Host > Settings. The page exposes the complete Host settings record. Every key on it is Host-owned: Host is the only module that ever writes it.

SettingMeaning, default
Host Id hostidSparkplug host application id, published as spBv1.0/STATE/<hostId>. Default SparkBridge. Read once at connect (restart to pick up a change). Must match the Edge tab's primaryHost.
Fold Target foldtargetTemplate member that receives folded UDT properties on projection. Read live, applies per projection. Owned by Host even though the matching fold/foldmembers keys live on the Edge tab; they are opposite ends of the same wire format, and changing one without the other silently breaks the property mapping.
Partition partitionNamespace slices this gateway owns, such as PlantA,PlantB. Use spBv1.0/# to claim the whole namespace explicitly. Hot; applies within about 5 seconds.

Secrets, including any broker password Host uses, go in the secrets file named by sparkbridge.secrets.file (default data/sparkbridge-secrets.properties), never as a -D argument.

hostId precedence exception: everywhere else, a saved settings-page value wins over the matching -D system property, which in turn wins over the historical default. hostId is the deliberate exception: an explicitly set -Dsparkbridge.host.id outranks the settings-page value. Set the Host Id field for the normal case; use the system property only when it must win regardless of what is saved.

This settings page supersedes the older /data/sparkbridge/config HTML form, which is being trimmed to host-only keys. Prefer Config > SparkBridge Host > Settings for new deployments.

Operate

6. Operate

Expand the managed tag provider (default name SparkBridge) in the Designer or gateway tag browser to watch live values. Host writes to Ignition's tag system, so normal tag history, alarming and scripting apply to it like any other provider.

On a site's Edge going offline, Host reflects the Sparkplug DEATH state on that node's tags rather than freezing stale values silently. On gateway restart, Host re-subscribes and rebuilds its provider from the current fleet BIRTH traffic.

REST status, node inventory and metrics routes require a bearer token; see sparkbridge.rest.readToken / sparkbridge.rest.token in the repo's docs/CONFIG.md.
