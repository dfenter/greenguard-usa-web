Spark61850

Substation IEDs, read natively over MMS

Most 61850 substation equipment reaches Ignition through a protocol gateway translating down to DNP3 or Modbus. That flattens the data model. GreenGuard USA built Spark61850 to speak MMS directly to the IED and read its logical nodes the way the standard defines them.

For your engineers

Spark61850 is a native IEC 61850 MMS client driver module for Ignition 8.1 and 8.3. It establishes MMS associations to IEDs and reads logical node data directly, verified against the libiec61850 reference implementation. A diagnostics folder reports association state per IED. Early access: the verification transcript and QA documents ship with the first release build.
