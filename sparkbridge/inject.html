What it does

One consumer, several destinations

The hard part of a cloud connector is not the API call. It is what happens when the link breaks and what happens when it comes back.

Exactly once

An offset token per row, not a hope

Every row carries a monotonic offset token. On restart the injector reads the channel's committed offset and resumes from it, so a row that already landed is skipped. Where the contract is ambiguous it errs toward a duplicate rather than a drop, and duplicates are removed by the token.

Outages

The buffer is the one SparkBridge already trusts

If Snowflake is unreachable the injector spills decoded rows to the same disk buffer that keeps the edge alive through a broken link. When the far end returns, the backlog replays in order and ahead of new data. Proven against a four-hour outage: 8,375 rows recovered, none lost, none duplicated.

Mapping

Routing is data, not code

A properties file maps each Sparkplug group to a database, schema and table. The default shape is entity-attribute-value, which absorbs a plant that adds metrics without a migration. A wide table is supported and falls back to EAV with a logged error rather than dropping the row.

Why it exists

The incumbent charges rent for a pipe

The commercial case is as plain as the technical one.

What you buy

  • A perpetual licence for a module you install on your own gateway.
  • Your Snowflake account, your warehouse, your bill. We are not in the path.
  • The service user holds insert on one schema and no warehouse rights at all.

What it will not do

  • It will not hold a password. Authentication is RSA key pair only.
  • It will not restamp a value on arrival, so a backfill draws the real curve.
  • It will not publish anything. The consumer has no write path to the bus.
