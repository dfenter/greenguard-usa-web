SparkBridge Core Modules

Shared install steps first, then Edge, Host, Provider and SparkFlow.

Installation

SparkBridge suite

Shared steps every SparkBridge module follows before its own configuration begins.

What it needs

  • An Ignition 8.1.19 or newer gateway that can be restarted at will.
  • The release package: SparkBridge-Provider.modl, SparkBridge-Host.modl, SparkBridge-Edge.modl, optionally SparkBridge-Flow.modl, plus SHA256SUMS.txt and sparkbridge-signing-cert.pem.

Install

  1. Download the bundle for your Ignition line.
  2. In the gateway, go to Config > Modules > Install or Upgrade a Module, and upload the modules in this order: Provider, then Host, then Edge (and Flow, if bought).
  3. Accept the certificate and license once; confirm all modules show Running.

The gateway checks each module's signature itself against the shipped certificate on upload. The fingerprint is published on the download page for anyone who wants to confirm it by hand.

Upgrade every installed module together. Host, Edge, and Provider agree on which settings key each of them owns and reads; a gateway running mixed old and new module versions can disagree on ownership for a key like hostId or foldtarget and silently misbehave. Upload all installed modules from the same release bundle in the same maintenance window.

License

FilePer-gateway license key at <data>/sparkbridge-license.key.
Re-check intervalEach module re-checks the key file every 30 seconds, so installing, replacing, or removing a key takes effect with no restart.

From release 2.7.0, every SparkBridge module runs on Ignition's standard two-hour module trial (the gateway's Reset Trial button restarts the clock). When the trial expires and no verified key names the product, each module pauses its data path but keeps configuration and buffers: the Edge publishes NDEATH and stops publishing while store-and-forward keeps capturing, the Host publishes a retained OFFLINE STATE and closes its sessions, the Provider's embedded broker refuses new connections while established ones are left alone, and Flow stops its dispatcher. A key dropped in after expiry lifts the pause on its own within the 30-second re-check, with no button press and no restart. A verified key overrides the trial entirely and the trial clock is then ignored.

Modules / Edge

SparkBridge Edge

Publishes gateway tags as Sparkplug B to the broker.

Install

Install after Provider and Host, following the shared install steps above. See INSTALL.md in the bundle for the full module inventory.

Configure

Config > SparkBridge Edge > Settings. Set source to the tag folder to publish, for example [default]Plant/Line1. The Edge polls its settings every five seconds and rebuilds its node runtime when edge-owned settings change; no restart is required. Every key below is Edge-owned: the Edge is the only module that ever writes it, and every one hot-reloads on that five-second poll.

SettingMeaning, default
sourceTag subscription root. Default [System]Gateway/Performance.
nodesExplicit group,edge,source;… runtime list, up to 8. Empty falls back to one implicit Ignition/Gateway runtime.
batchmsNDATA batch window, milliseconds. Default 100.
deadbandPublish deadband fraction. Default 0.0.
unsTurns on the UNS application-topic mirror. Default off.
unsprefixApplication topic prefix used by the UNS mirror. Default sparkbridge.
foldFolds UDT property members into the published Template. Default off. Must agree with the Host tab's Fold Target below — an operator who changes one without the other silently loses the property mapping.
foldmembersName patterns matched for folding. Default Units,Description,Address*,IO_Loc*,Number,PV_L,PV_U.
primaryHostHost application id this edge watches for STATE. Must match the Host tab's Host Id. Default SparkBridge.
maxtagsDiscovery cap on tag count. Default 250000.
subchunkSubscription chunk size. Default 10000.
rescansecTag rescan period, seconds. Default 300.
devicelevelDevice modeling depth, 0 disables it, max 8. Default 0.
devicefoldersFolder markers used for device modeling. Default empty.
devicewritableDevice ids that accept DCMD writes. Default empty.
sfhoursStore-and-forward retention target, hours, 0-8760. Default 24.
sfmaxStore-and-forward hard byte cap. Blank derives it from the retention target.

Edge-only identity and enrollment stay as -D system properties, not on this page: sparkbridge.edge.username, sparkbridge.edge.password (secrets file, never the command line), and sparkbridge.enrollment.code (one-time first-boot code against Host; the Edge clears it after success).

Verify

Check the gateway log for the startup and BIRTH lines:

SparkBridge Edge: built 1 runtime(s), generation 1
SparkBridge Host: BIRTH Ignition/Gateway (N metrics)

A second BIRTH ... (N metrics) line with a changed metric count confirms a settings change was picked up.

License

Covered by the suite license key described in the shared install steps. On trial expiry with no verified key, the Edge publishes NDEATH and stops publishing; store-and-forward continues capturing.

Modules / Host

SparkBridge Host

Decodes Sparkplug B into a managed Ignition tag provider. Module file: SparkBridge-Host.modl.

What it needs

A running Provider (embedded broker or external HiveMQ CE) that Host can subscribe to before any Edge publishes.

Install

Install after Provider and before Edge, following the shared install steps above.

Configure

Open Config > SparkBridge Host > Settings. The page exposes the complete Host settings record. Every key on this page is Host-owned: the Host is the only module that ever writes it.

Host Id hostidSparkplug host application id, published as spBv1.0/STATE/<hostId>. Default SparkBridge. Read once at connect (restart to pick up a change). Must match the Edge tab's primaryHost.
Fold Target foldtargetTemplate member that receives folded UDT properties on projection. Read live, applies per projection. Owned by Host even though the matching fold/foldmembers keys live on the Edge tab — they're opposite ends of the same wire format, and changing one without the other silently breaks the property mapping.
Partition partitionNamespace slices this gateway owns, such as PlantA,PlantB. Use spBv1.0/# to claim the whole namespace explicitly. The value is hot and applies within about 5 seconds.

Secrets, including any broker password Host uses, go in the secrets file named by sparkbridge.secrets.file (default data/sparkbridge-secrets.properties), never as a -D argument.

hostId precedence exception: everywhere else, a saved settings-page value wins over the matching -D system property, which in turn wins over the historical default. hostId is the one deliberate exception — an explicitly set -Dsparkbridge.host.id outranks the settings-page value. Set the Host Id field on this page for the normal case; use the system property only when you need it to win regardless of what's saved.

This page supersedes the older /data/sparkbridge/config HTML form, which is being trimmed to host-only keys. Prefer the Config > SparkBridge Host > Settings page for new deployments.

Verify

SparkBridge Host: ... subscribed
SparkBridge Host: BIRTH Ignition/Gateway (N metrics)

Expand the managed tag provider (default name SparkBridge) in the Designer or gateway tag browser and confirm values update. The REST status, node inventory, and metrics routes require a bearer token; see sparkbridge.rest.readToken / sparkbridge.rest.token in docs/CONFIG.md.

License

Covered by the suite license key described in the shared install steps. On trial expiry with no verified key, Host publishes a retained OFFLINE STATE and closes its sessions.

Modules / Provider

SparkBridge Provider

Broker control: an embedded Moquette MQTT broker, or defers to an external HiveMQ CE broker with the SparkBridge authorization extension.

What it needs

Nothing extra for the embedded broker. For external HiveMQ CE: a JDK 11 or newer on the broker host, plus the SparkBridge broker authorization extension and the HiveMQ file-RBAC extension.

Install

Install first, before Host and Edge, following the shared install steps above. With no sparkbridge.* system properties set, the Provider binds the embedded Moquette broker on 127.0.0.1:1883 and, with TLS enabled, 127.0.0.1:8883.

Configure

Primary path: open Config > SparkBridge Provider > Settings. Two keys on this page are editable, both Provider-owned and both read once at startup (restart to apply a change):

broker.portEmbedded Moquette plaintext listener port. Default 1883.
broker.tlsportEmbedded Moquette TLS listener port. Default 8883.

Everything else on the page is a read-only audit of the broker's effective running posture — implementation, broker endpoints, bind host, TLS, plaintext, client authentication, keystore, identities, edge scopes, application topics, and secrets status. Secrets are never shown in the clear: a configured broker password renders only as a boolean, for example Broker password configured: true.

Broker-extension RBAC

For external HiveMQ CE, configure the separate broker-extension on the broker host. Its file-based RBAC uses extensions/sparkbridge-auth/sparkbridge-auth.properties for sparkbridge.broker.hostuser, sparkbridge.broker.edgescopes, sparkbridge.broker.hosttopics, sparkbridge.broker.apptopics, and sparkbridge.broker.appprefixes. HiveMQ's credentials.xml carries the broker credentials and password hashes. Keep its identities and scopes aligned with the Provider settings page.

Verify

Embedded broker, gateway log:

SparkBridge Provider: ... broker

External broker, gateway log:

SparkBridge Provider: broker.impl='external', embedded broker disabled

Config > SparkBridge Provider > Settings, under Posture, shows the running values rather than the file's intent. A property that does not appear there indicates a configuration gap.

License

Covered by the suite license key described in the shared install steps. On trial expiry with no verified key, the embedded broker refuses new connections while established sessions are left alone.

SparkFlow

Bridges Sparkplug B to a NATS/JetStream backbone. Module file: SparkBridge-Flow.modl.

What it needs

A reachable nats-server with JetStream enabled. SparkFlow is optional and is not part of the core install; install it after Host. See docs/FLOW_MODULE.md in the bundle for the full configuration and lifecycle reference.

Install

Install after Provider, Host, and Edge are running, following the shared install steps above.

Configure

SettingMeaning, default
sparkbridge.flow.enabledMaster on/off switch. Default true. When false, startup logs and returns without connecting to NATS or the broker.
sparkbridge.flow.nats.urlNATS core connect URL. Default nats://127.0.0.1:4222.

modules / sparkcalc

SparkCalc

Computes declared expressions on the live Sparkplug estate and publishes results as their own identity so a derived value is never mistaken for a measured one.

What it needs

  • A SparkBridge Host gateway.

Install

SparkCalc comes with the Host license. Install it through Config > Modules > Install or Upgrade a Module; no build step is required.

Configure

Declared expressions, staleness budgets, and identity settings are documented in the module's own README and in docs/LIVEPROOF.md. See the README in the bundle for the full property list; only what is confirmed there is listed below.

SettingResults publish under a Calc-<group> identity, with its own edge node and bdSeq lifecycle, distinct from the plant's own identity.
SettingEvery declared input has its own staleness budget; there is no single global staleness setting.

Verify

Confirm published metrics appear under the Calc-<group> edge node rather than under the plant's own edge, and that the reported timestamp is the stalest contributing input's source timestamp, not the evaluation time. Full proof steps are in docs/LIVEPROOF.md.

License

Included with SparkBridge Host.

modules / sparkid

SparkID

Generates broker authorization from a declared statement of intent, so a Sparkplug estate's access rules are never hand-typed wildcards.

What it needs

  • A SparkBridge Host gateway.

Install

SparkID comes with the Host license. Install the module through Config > Modules > Install or Upgrade a Module; no build step is required.

Configure

The .intent file is a declarative access policy designed for infrastructure-as-code review and diffing. Write the policy, validate it, issue identity secrets, preview the broker change, then generate the deployment artifacts:

  1. Validate the written declaration: 
    sparkid validate --intent examples/sparkbridge-dev.intent
  2. Issue one secret per identity and record it in the ledger: 
    sparkid issue --intent examples/sparkbridge-dev.intent --ledger out/estate.ledger --out-dir out
  3. Preview the change against the broker's current rules: 
    sparkid diff --intent examples/sparkbridge-dev.intent --current /path/to/credentials.xml
  4. Generate the reviewed deployment artifacts: 
    sparkid generate --intent examples/sparkbridge-dev.intent --ledger out/estate.ledger --out-dir out --current /path/to/credentials.xml
SettingHiveMQ file-RBAC is the only supported broker target for credentials.xml. Mosquitto dynamic-security is supported with --mosquitto, writing dynamic-security.json.
SettingSparkID never writes into a running broker and never opens a network connection; installing generated artifacts and restarting the broker is a separate, deliberate step.

Verify

Run sparkid diff against the broker's current credentials.xml and confirm the reported changes match intent. Check credential age with sparkid expiry. Full acceptance runs are in docs/ACCEPTANCE.md.

License

Soft-licensed; runs the same whether or not a key is present. License file lookup order: --license <file>, the SPARKBRIDGE_LICENSE environment variable, then ./sparkbridge-license.key in the working directory. Run sparkid license for full status.

unsbridge.spike.enabledEnable the synthetic proof node. Default false.
unsbridge.server.allowAnonymousUnencryptedRemoteExplicit acknowledgement for remote anonymous unencrypted access. Default false.

License

Free. Included with any SparkBridge Edge or Host license; ships as a free module with no license tag required.

modules / sentinel

Sentinel

Audits a Sparkplug estate's posture and grades it without ever touching it.

What it needs

  • A SparkBridge Host gateway (for the estate being audited).
  • The signed Sentinel release from the SparkBridge bundle.

Install

Sentinel carries its own license. Install the signed release through Config > Modules > Install or Upgrade a Module; no build step is required.

Configure

Sentinel runs as a passive audit by default:

java -jar sparkaudit-0.1.0-all.jar \
  --broker tcp://broker.example:1883 --username auditor \
  --password-file secrets.properties audit.password \
  --estate "Plant 4" --window 300 --expect-groups Plant4,Utilities \
  --out-html report.html --out-json report.json
Setting--credentials-xml and --posture add config-derived findings the wire cannot show on its own.
Setting--allow-active-probes enables active probes (off by default); --tls-listener checks a TLS listener.
Setting--profile free withholds full evidence for a pre-sales report; --profile full (default) includes complete evidence and remediation.

The auditor never publishes to any topic; it exposes no publish method at all.

Verify

Run the audit and check the exit code: 0 clean, 1 findings below critical, 2 at least one critical, 3 the audit could not run. Use --capture-out capture.jsonl and later --replay capture.jsonl to re-evaluate rules offline against the same window.

License

Soft-licensed; runs in full whether or not licensed. License file sparkbridge-license.key in the working directory, or --license <file>, or the SPARKBRIDGE_LICENSE environment variable. Run sparkaudit license for full status. Buy at https://mqtt.greenguard-usa.com/sparkbridge/pricing.

modules / fleetops

FleetOps

Operates many Ignition gateways as one fleet: an agent on each gateway reports its real state, a console holds desired state, and the difference is drift.

What it needs

  • A SparkBridge Host gateway to run the console role; the agent role runs on every fleet member.
  • The signed FleetOps module from the SparkBridge bundle.

Install

FleetOps carries its own license. Install the signed module through Config > Modules > Install or Upgrade a Module; no build step is required.

Configure

A JVM system property wins; otherwise settings come from <dataDir>/fleetops/fleetops.properties. Secrets are the exception: the broker password and REST token come only from the file named by fleetops.secrets.file, which must be mode 600.

fleetops.agent.enabledfalse by default; a module dropped on a gateway must not silently join a fleet.
fleetops.console.enabledfalse by default.
fleetops.broker.uridefault tcp://127.0.0.1:1883.
fleetops.trustedkeybase64 P-256 public key. Absent means the agent reports and accepts nothing.
fleetops.action.allowlistcomma-separated action names; empty means no action is permitted.
fleetops.action.certReplaceEnabledfalse by default; second explicit local gate for the private-key-bearing CERT_REPLACE action.
fleetops.agent.intervalSecondsdefault 60, floor of 5; this is also the drift-detection latency.

Full property list is in the module README's Configuration section.

Verify

Use the operator CLI to publish desired state and issue a signed action, then confirm the fleet converges: 

java -jar ... publish-desired --key fleet-signing.key --site Austin/Site12 \
        --file desired.properties --version 2026-08-16.1 --broker tcp://host:1883
java -jar ... watch --broker tcp://host:1883 --seconds 30 --report drift
Full multi-site rig proof is in docs/LIVEPROOF.md and docs/rig-transcript.txt.

License

See the README in the bundle.

modules / sparkinject

SparkInject

Perpetual-license Sparkplug-to-cloud injection for Ignition, landing estate data in Snowflake or Databricks with store-and-forward and exactly-once semantics.

What it needs

  • A SparkBridge Host gateway.
  • A Snowflake or Databricks destination, provisioned before switching off the default JSONL sink.

Install

  1. SparkInject carries its own license. Install the signed module through Config > Modules > Install or Upgrade a Module; no build step is required.
  2. Set sparkinject.enabled=true; it is off by default.
  3. Leave sparkinject.sink=jsonl (the default) to prove the pipeline end to end before provisioning a warehouse.

Configure

Before switching sparkinject.sink=snowpipe, run the generated DDL at docs/sparkinject-schema.sql to create the database, schema, and one table per mapped group, plus the role and key-pair user with USAGE and INSERT, SELECT grants. The module cannot create tables itself.

sparkinject.enabledfalse by default.
sparkinject.sinkjsonl (default) or snowpipe; databricks for that destination.
sparkinject.mapping.filedefault data/sparkinject-mapping.properties, group-to-table routing.
sparkinject.mapping.requireRulefalse by default; true refuses an unmapped group instead of deriving a table name.
sparkinject.secrets.filedefault data/sparkinject-secrets.properties, mode 600, never on the JVM command line.
sparkinject.broker.uridefault tcp://127.0.0.1:1883.
sparkinject.snowflake.privateKeysecrets-file key; PEM PKCS#8 private key for the Snowflake key-pair user.
sparkinject.status.tokensecrets-file key; bearer token for status.json, unset means loopback-only.

Verify

Check GET /data/io.sparkinject.snowflake/status.json. A lane in state BLOCKED always carries a non-null problem with pasteable remediation, for example a missing destination table. inject.buffered reports bytes currently held on disk and is the number to alarm on.

License

Perpetual license. See the README in the bundle for purchasing.

Device Drivers

Each installs on any Ignition gateway and appears as a device type.

Drivers / Allen-Bradley Logix

SparkLogix

Ignition's built-in Logix driver reads slowly and falls over on large or restricted tag sets. SparkLogix exists because that built-in driver performs badly under load: it connects straight to ControlLogix and CompactLogix controllers over EtherNet/IP, browses UDTs directly, plans reads per tag, and never lets a restricted tag block the rest of the read.

What it needs

  • Ignition 8.1.x (legacy driver API) or Ignition 8.3.x (managed-node API, separate module build), Java 17.
  • A ControlLogix or CompactLogix controller reachable over EtherNet/IP, firmware v16 or later. Micro8xx and 5000-series are lower priority targets on the same CIP core.

Install

  1. On the target gateway, install the sparklogix-<version>-ign83.modl artifact (8.3) or the 8.1 build of the same module.
  2. Confirm the module is active and its module ID reads com.sparkbridge.sparklogix.
  3. To upgrade, install the new version over the same module ID without uninstalling the old one first; existing devices and settings are retained.

Configure

Config > OPC UA > Device Connections > Create new Device > the SparkLogix Logix device type. The settings form has five categories: Communications, Timeouts, Probe Options, Redundancy, Advanced.

SettingMeaning, default
Network AddressDNS or IP of the first hop, optional :port.
Route PathSubsequent hops, for example 1,0 for a ControlLogix backplane slot; blank for an on-board Ethernet port.
Use Connected / Allow BatchingClass 3 connected messaging and Multiple Service Packet batching of small requests.
Use Instance IDsOff by default. Leave off; the instance-ID/symbolic fallback path is not independently field-verified yet.
Enable Class 1 CyclicOff by default.
Change DetectionOn by default, tag-database change polling.
Persist Tag DatabaseOn by default.
Verify WritesOff by default.

Verify

  1. Start the device and confirm it reaches CONNECTED and the first probe populates the tag database.
  2. Browse or type a tag path, for example an array member such as Entity.Params[0], and confirm distinct values per element (the array sentinel regression check).

Security notes

Classic S7comm is plaintext with no credentials, encryption, or replay protection; this is a limitation of the Siemens protocol, not an omitted driver option. Isolate TCP 102 on a dedicated VLAN or VPN and firewall it so only the Ignition gateway can reach the PLC. Do not expose the PLC on an untrusted or internet-routable network.

S7comm+ transport is disabled by default because it fails against tested real hardware. It can only be enabled with the system property sparks7.allowPlus=true (or environment variable SPARKS7_ALLOW_PLUS=true), and only on a trusted test network.
