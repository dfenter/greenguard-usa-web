SparkGantt

A Gantt chart that still scrolls smoothly at 500 tasks

Perspective has no built-in Gantt component. Schedules end up as a table nobody can scan, or a custom view that bogs down past a hundred rows. GreenGuard USA built SparkGantt as a virtualized Perspective component for real production schedules: 500 or more tasks, still smooth.

Situations This Solves

Each row is a schedule that Perspective's default building blocks cannot render or track well at production size.

The situationWhat changes
A schedule view chokes past a hundred rows
Any Perspective project trying to show a real production or maintenance schedule.		 SparkGantt only renders the rows in the visible viewport to the DOM. The component stays responsive whether it is bound to 50 tasks or 5,000.
Perspective has no native Gantt component
Anyone who has built one from styled divs and a repeater, then hit its limits.		 SparkGantt drops in as a standard Perspective component with task, dependency and milestone bindings. No hand-rolled layout to re-debug every time the data shape changes.
Dependencies and milestones live in a separate table
Schedulers cross-referencing a task table against a dependency table to understand the plan.		 Dependency lines and milestones render directly on the chart from their own bound properties. The relationship between tasks is visible instead of inferred.
A schedule that only makes sense zoomed out, or only zoomed in
Planners toggling between a shift view and a monthly view in separate screens.		 Zoom and pan are built into the component. The same bound data supports a tight shift view and a wide monthly view without two screens to maintain.

SparkGantt ships in the 2.7.0 bundle for both Ignition lines. Download it or read the docs.

For your engineers

SparkGantt is a Perspective component module for Ignition 8.1 and 8.3. It virtualizes row rendering so only the visible viewport touches the DOM, keeping frame rate steady well past 500 tasks. Bindings cover tasks, dependencies and milestones, with zoom and pan built in.
