Point it at the controller. The tags are already there.

SparkLogix connects to ControlLogix and CompactLogix controllers over EtherNet/IP and browses the tag database directly from the gateway, no OPC server and no translator box to license, patch or lose a reading to. Tags, including nested user-defined types, appear the moment the controller connects.

Reads are planned around what each tag actually needs rather than one setting for the whole controller: values that share a structure are read together where that is faster, and everything else is read on its own so a locked or restricted tag never holds up the rest. The connection itself is built to stay up, recovering on its own if a request goes quiet without a stalled tag ever going unnoticed.

For your engineers

SparkLogix is a native ControlLogix / CompactLogix driver over EtherNet/IP for Ignition 8.1 and 8.3, version 0.2.0. Reads are cost-planned per tag: whole-structure coalescing for fully readable UDTs and AOIs, per-member reads for standalone scalars, bit hosts, and partially restricted structures, all deduped and packed into Multiple Service Packets sized to the negotiated connection buffer. Oversized readable tags are served with Read Tag Fragmented, assembled off the event loop. Class 3 connections use Large Forward Open with UCMM fallback, spread across a small connection pool that scales with concurrency. The tag and type database persists to disk for an instant warm start and reprobes on a background schedule, with access-restriction learning cleared on every reprobe so a Studio 5000 fix can never leave a stale denial in place. A stall watchdog force-reconnects a connection that has gone quiet even when the transport still looks alive. Writes are type-aware and batched, with bit writes coalesced as read-modify-write and marked non-retryable so a timed-out write is never silently resent; write verification is optional and off by default. On redundant gateways, only the active node holds Class 3 connections, with fail-open behavior if redundancy state is unavailable. 233 tests cover the common protocol layer, the core engine, and both the 8.1 and 8.3 gateway adapters.
