the core modules

Edge at Every Site. Host Once.

SparkBridge Edge

Move plant data reliably.

Publishes your Ignition tags on change, holds them on disk through an outage, and replays them in order with the original timestamps.

SparkBridge Host

Turn many sites into one system.

Subscribes every site into one namespace, learns each site's model from its birth certificate, and hosts the optional modules.

SparkBridge Provider

Sparkplug-aware broker.

Required broker infrastructure. Embedded Moquette for a single node, or a HiveMQ CE companion service for MQTT 5 and shared subscriptions. $1,995 per gateway, priced separately.
why

Six Reasons

Survive outages

Edge buffers to disk when the link drops and replays in order when it returns. Nothing is lost.

Preserve source timestamps

Every value keeps the time your equipment gave it, through an outage and back. Trends stay true.

Scale horizontally

Consumers share one stream and standbys take over in 244 ms. Add a site or a server without a ceiling.

Eliminate polling

A site sends a value once, when it changes. Nothing asks the plant for every tag on a timer.

One namespace

Every site publishes into one tree. Every tool subscribes to the same names.

No per-tag pricing

One license per gateway. Tags, devices and connected clients are never counted.
