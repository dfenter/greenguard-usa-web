# Orbit Hearts licenses

All art, characters, prose, music, sound effects, icons and UI chrome in this
directory are original GreenGuard USA work created for Orbit Hearts. No harvested
pack files, no remote assets, and no references to any other title directory.

- `game.js` - original GreenGuard USA code. Every frame of art is composed
  procedurally in code (station locales, character portraits, particles, UI
  chrome) and baked into canvas textures at load time.
- `story.js` - original GreenGuard USA writing. Characters, station, dialogue,
  endings and memory fragments are original fiction.
- `assets/music-drift.mp3`, `assets/music-station.mp3`, `assets/music-orbit.mp3` -
  original procedural music beds rendered offline for this title, mono mp3.
- `assets/sfx-*.mp3` - fifteen original procedural sound effects rendered offline
  for this title, mono mp3. No ogg is shipped, per the mobile audio format law.
- `icon.png`, `icon512.png`, `favicon.png` - original GreenGuard USA icon render.
- `phaser.min.js` and `ggkit.js` are shared runtime files covered by
  [`play/_shared/LICENSES.md`](../_shared/LICENSES.md).

Pack level provenance rules for the fleet live in
[`play/_assets/LEDGER.md`](../_assets/LEDGER.md). This title ships no rows from
that ledger because it uses no harvested pack files.
