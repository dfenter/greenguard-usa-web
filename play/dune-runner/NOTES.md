# Dune Runner

Controls: drag the left wheel or anywhere on the left half to steer; hold THROTTLE to accelerate; BRAKE slows you down; arrows/WASD also work.
Loop: follow the compass, tag every gold flag in a checkpoint raid before its 60-second timer, and refuel only while coasting inside an oasis.
Fuel depletion triggers a walk-back to the nearest oasis for a 25-point penalty. Five raids clear the route; END RUN banks the session score.
Best score is saved in localStorage. Portrait mode shows a rotate prompt; the game runs underneath it.
