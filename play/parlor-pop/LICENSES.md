# Parlor Pop licenses

Parlor Pop uses no third-party art or code assets beyond the shared runtime.
All visible room art, tiles, icons, particles, and UI chrome are procedurally
drawn in `game.js`. The short MP3 cues in `assets/` are original procedural
tones rendered for this title.

The shared Phaser runtime and GGKit license coverage is recorded in
`play/_shared/LICENSES.md`. Asset policy and provenance ledger:
`play/_assets/LEDGER.md`.
