# Aftergate - asset and code provenance

## Summary

Aftergate ships **zero third-party media files**. There is no image, audio,
font or data file in this directory that came from an asset pack. Every
sprite, panel, particle, icon, landmark, wall, sound effect and music stem is
generated procedurally in code at boot:

- **Graphics** - `ag_art.js` draws each texture with Phaser `Graphics` and
  bakes it once into a canvas texture (`generateTexture`), then destroys the
  Graphics object. Nothing static is left in the display list.
- **Audio** - `ag_art.js` synthesises 16-bit PCM into `Float32Array`s,
  encodes RIFF/WAVE in memory, and hands the resulting `Blob` object URLs to
  the GGKit audio bus. No `.mp3`, `.m4a`, `.ogg` or `.wav` file is shipped or
  fetched. (The fleet rule "audio mp3/m4a only, never ogg" is satisfied
  trivially: no encoded audio file exists.)

## Asset ledger

Per `/play/_assets/LEDGER.md`, every shipped asset file must trace to a pack
row in that ledger plus a file-level row here. **Aftergate consumes no row in
the ledger**: it curates no cut from `web2d/ui-pack`, `web2d/particle-pack`,
`web2d/tiny-town`, `web2d/impact-sounds`, `web2d/music`, or any other pack
listed there, and it hotlinks no other title's `assets/` directory. The
ledger's "Used by" column therefore needs no update for this title.

If a future revision does curate pack files into `play/aftergate/assets/`,
that revision must add the per-file rows here and update
`/play/_assets/LEDGER.md`.

title. No trademarked or third-party character, likeness, logo, level layout
