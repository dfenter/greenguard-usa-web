# Touchline Eleven asset and code licenses

Rev 1, 2026-08-13. This title is an original GreenGuard USA production for
Fleet F13. It ships procedural art and original procedural audio only.

## Asset provenance

No harvested pack file is copied into this directory. The provenance rules and
the available CC0 packs were checked in `/play/_assets/LEDGER.md`, and the
visual rules were checked against `/play/_assets/ART_arcade2d.md` (including its
sports note) and `/play/_assets/UI_LAW.md`. No ledger pack is consumed by this
title, so no "Used by" row in the ledger changes.

Every pitch, stand, crowd band, floodlight pool, weather tint, line marking,
goal net, player figure, ball, particle, button, panel, medal, crest and menu
backdrop is drawn from code into a canvas texture at load time by `te_art.js`.
The only binary art files in this directory are the app mark below, which is
generated by the same procedural design.

All audio is synthesized in `te_art.js` at load into 22 kHz mono WAV object
URLs and played through the GGKit audio buses. There are no audio files in this
directory, no samples, and no remote or network audio of any kind. The OGG
format is therefore never present, in line with the 2026-08-06 audio format
law.
