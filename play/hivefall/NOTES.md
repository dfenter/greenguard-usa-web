# Hivefall
Controls: swipe (or drag) a gem on the lower board to swap; keyboard = arrows to move, Space/Enter to pick then arrow to swap, R restart fight, M mute. Shop: arrows + Enter to buy, F/Space to deploy.
Loop: matches fire weapons up the matching lane column at the swarm marching down the upper half - red cannon, blue frost, green wall repair, gold coins, violet venom; 4-runs splash, 5-runs pierce, cascades multiply power.
Fail/Win: wall hits 0 = retry the same fight (coins kept); clear all 20 fights = run won.
Between fights spend earned coins on 4 gear tracks (gun calibre, frost coils, wall plating, salvage rig, 8 levels each). Everything is play-earned; progress persists in localStorage.
