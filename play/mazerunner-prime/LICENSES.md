# Mazerunner Prime licenses

## Original game code and generated art

`game.js` and the in-game maze, runner, chaser silhouettes, particles, HUD, icons, and audio tones are original GreenGuard USA procedural work for Mazerunner Prime. No external art or audio URLs are used.

## Shared runtime

Phaser 3 is loaded only from `/play/_shared/phaser.min.js`. GGKit is loaded only from `/play/_shared/ggkit.js` and owns lifecycle, input, saves, audio buses, settings, and PWA registration. Shared runtime licensing is covered by `/play/_shared/LICENSES.md`.

## Asset ledger

The project was checked against `/play/_assets/LEDGER.md`. No harvested pack files are shipped by this title. The local MP3 files are generated procedural tones and remain MP3-only as required.
