spBv1.0/sparkbridge/NDATA/assurance

How It Is Tested

Everything below ships with the product and can be re-run on your own hardware.

Tests

360+ automated tests

Live gateway integration, property-based codec testing, a 50,000-case malformed-input fuzz of the decoder, corrupt-buffer and chaos suites, and negative TLS tests confirming untrusted certificates are rejected.

Load

Nine load scenarios

Codec scaling, latency distribution, fan-in, sustained soak with heap-stability checks, outage and replay, multi-broker scale-out, 5,000-node fleet tracking, churn endurance, and the 500,000-metric capacity acceptance.

Review

Four independent code reviews

Independent review passes over correctness, security, QA and performance, including a deliberate re-review of the fixes themselves, which re-opened half of them and found two defects the fixes had introduced. All closed.

Analysis

Code analysis

Clean high-priority static analysis, 89% mutation-test strength on the pure-logic core, and dependency auditing against known vulnerabilities.

Versions

Ignition 8.1.19+

The data path is compiled against the 8.1.0 API and the bytecode targets Java 11, so nothing reaches for a later method or a later JVM. Runtime-verified on 8.1.38.

Honesty

Direct support

You deal with the engineers who wrote the code. Support and updates are included with Enterprise licences and optional on a site licence.
