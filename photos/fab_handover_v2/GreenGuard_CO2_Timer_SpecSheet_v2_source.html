CO2 Trap Timer v2

ATtiny85 · DS3231 RTC · TM1637 Display · Hardcoded Schedule · 9V Battery or DC Adapter Input

Overview

The GreenGuard CO2 Trap Timer v2 is a standalone 24-hour timer for GreenGuard CO2 mosquito traps. It opens a solenoid valve at a fixed ON time and closes it at a fixed OFF time, maintaining a programmed schedule without user intervention. The DS3231 real-time clock preserves the schedule without a coin cell by powering VBAT from the 3.3 V rail.

The TM1637 4-digit display shows the current time (HH:MM) and two tactile buttons allow the user to set the RTC time in the field.

Default Schedule

EventTime
CO2 ON (valve opens)05:30
CO2 OFF (valve closes)23:30

Schedule is hardcoded in firmware. Field-adjustable only by reflashing.
